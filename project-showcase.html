Project Abstract

Farm2Home is a frontend web application designed to connect farmers directly with consumers. It provides a responsive marketplace to browse and search farm products, view prices and farmer information, save favourites, manage a shopping cart, and complete a simulated checkout.

The project is built using HTML5, CSS3, and vanilla JavaScript. Browser LocalStorage is used to demonstrate data persistence without a server-side backend. The prototype showcases a connected shopping flow and farmer-oriented product management.

Current scope: academic demonstration only. Authentication, orders, and checkout are browser-based simulations; a production release would require a secure backend, database, and real payment integration.

  • Direct farmer-to-consumer product discovery
  • Search, category filters, favourites, cart, and checkout
  • Farmer profiles and product management
  • Responsive layout for desktop and mobile
